# Backend

Сервер приложения «Тихий друг».

Планируемый стек:

- Python 3.12, FastAPI
- PostgreSQL
- Docker и Docker Compose для запуска
- APScheduler для еженедельной генерации отчётов
- GigaChat API или Yandex AI Studio для ИИ-отчётов (через отдельный модуль-адаптер)

Код появится на этапе разработки бэкенда.
