== О проекте

Мобильное приложение для Android: записи, отметки настроения и недельный ИИ-отчёт.

Бизнес-постановка и требования ведутся в Confluence, раздел «Тихий друг»:

* Бизнес-постановка MVP
* Юридические документы
* Тексты сообщений поддержки
* Словарь тревожных фраз
