== Формат хранения

Словарь хранится в конфигурации на сервере в виде JSON, кэшируется на устройстве и обновляется без выпуска новой версии приложения. Для каждой категории — список шаблонов (основы слов или регулярные выражения), чтобы учитывать разные формы слов.

Поля:

* `version` — версия словаря;
* `categories` — список категорий;
* для каждой категории: `code`, `patterns` (список шаблонов), `messages` (ссылки на тексты сообщений).

== Правила проверки

. Текст записи нормализуется: нижний регистр, замена «ё» на «е», удаление лишних знаков.
. Текст сравнивается с шаблонами всех категорий.
. При совпадении показывается случайное сообщение из категории, у записи ставится признак срабатывания, который передаётся на бэкенд вместе с записью для недельного отчёта.
