# Тихий друг (quiet-friend)

Тихий друг — мобильное приложение для Android: дневник записей и настроения с недельным ИИ-отчётом. Пользователь делает короткие записи (текстом или голосом) и отмечает эмоции в течение дня, а раз в неделю получает отчёт: какие эмоции преобладали, о чём он чаще думал и что его радовало.

Приложение не является медицинским и не заменяет помощь специалиста.

## Состав репозитория

| Папка | Что внутри |
| --- | --- |
